# 정규식 baseline과 LLM 비교

LLM 숫자는 커밋된 리포트 `reports/extract-new.md`·`reports/extract-tune.md`에서 읽었다. LLM을 다시 부르지 않았고 OpenAI API를 쓰지 않았다. 정규식 숫자는 규칙을 고정한 뒤 `reports/regex-new.md`·`regex-tune.md`·`regex-more.md`와 같은 규칙으로 센 값이다. 칸은 공고 하나 × 필드 하나이고 청약홈 정답이 있는 칸만 센다.
